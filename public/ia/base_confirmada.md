## NÚCLEO SISTAFE
- SISTAFE = Sistema de Administração Financeira do Estado
- Base legal = Lei n.º 14/2020, de 23 de Dezembro
- e-SISTAFE = sistema informático que operacionaliza o SISTAFE (CEDSIF, IP)
- CEDSIF, IP = Centro de Desenvolvimento de Sistemas de Informação de Finanças
- NÃO EXISTE como grafia correcta: CEDECIF, TUFE
- NÃO CITAR como facto: "Decreto 32/2019" (armadilha de alucinação)

## SUBSISTEMAS (Lei 14/2020) — seis
1. SPO — Planeamento e Orçamento (PESOE; módulo MPO)
2. STE / STP — Tesouro Público (CUT)
3. SCP — Contabilidade Pública
4. SPE — Património do Estado (módulo MPE)
5. SCI / SAI — Controlo / Auditoria Interna
6. SAE — Aquisições do Estado (NOVO, Art. 52)

## MÓDULOS

- MEX — Execução

## PERFIS
- AEO — Agente de Execução Orçamental (cabimenta / fase orçamental)
- AEF — Agente de Execução Financeira (paga com processo válido)
- Controlo Interno — confere; não executa
- Ordenador — autoriza
- Admin Segurança — acessos; não executa despesa
